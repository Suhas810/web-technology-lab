## 📖 About the Lab

The Web Technology Lab focuses on developing practical knowledge of fundamental web technologies and creating web pages using HTML, CSS, and related technologies.

The experiments in this repository are organized according to the laboratory work and are intended for academic learning, practice, and reference.

---

## 🛠️ Technologies Used

The programs in this repository primarily use:

- **HTML5**
- **CSS3**
- **JavaScript**
- Web development fundamentals

### HTML Concepts

The experiments demonstrate concepts such as:

- HTML document structure
- Head and body sections
- Headings
- Tables
- Table headers
- Table body
- Table footer
- `rowspan`
- `colspan`
- HTML classes
- Table cells and rows

### CSS Concepts

The programs also demonstrate:

- CSS inside HTML documents
- Font styling
- Text alignment
- Background colors
- Borders
- Padding
- Table width
- Table positioning
- Alternating row colors
- Custom CSS classes
